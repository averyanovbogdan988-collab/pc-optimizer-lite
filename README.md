# pc-optimizer-lite

Приложение для оптимизации OBS, VTube Studio и игр под игровой ноутбук.

## Wi-Fi Doctor

Проверка всех настроек Wi-Fi и сети Windows с устранением того, что мешает
стабильному стриму и игре: энергосбережение адаптера, автоподключение к чужим
сетям, мёртвый DNS и прокси, перехват маршрута виртуальными адаптерами,
урезанный MTU, раздача обновлений в фон и прочее.

**Запуск:** двойной клик по `scripts/wifi-doctor.cmd` — сам запросит права
администратора и покажет меню.

```powershell
.\scripts\Wifi-Doctor.ps1                 # только диагностика, ничего не меняет
.\scripts\Wifi-Doctor.ps1 -Fix            # убрать то, что мешает
.\scripts\Wifi-Doctor.ps1 -Restore last   # откатить изменения
```

Перед каждым изменением пишется бэкап в
`%LOCALAPPDATA%\pc-optimizer-lite\`, любой запуск можно полностью откатить.

Полный список проверок, что именно правится и что скрипт намеренно
не трогает — в [docs/wifi.md](docs/wifi.md).

Требования: Windows 10/11, PowerShell 5.1 (встроенный), права администратора
для исправлений.
